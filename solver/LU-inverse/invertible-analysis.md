# 矩阵可逆性分析报告

## 1. 测试概述

测试了 3 个 benchmark 文件中的全部 288 个 40×40 矩阵，分析其数值可逆性。

**可逆性判定标准**：
- 使用 LAPACK `dgetrf_` 进行 LU 分解
- `info = 0` 且最小主元 > 1e-12 判定为**数值可逆**
- 最小主元 < 1e-12 判定为**病态（数值奇异）**

## 3. 矩阵特性分析

### 3.1 可逆矩阵特征

| 特征 | 量级 |
|------|------|
| 最小主元 | 20 - 40 |
| 最大主元 | 500 - 2000 |
| 条件数 κ(A) | 60 - 3×10⁵ |
| 数值性态 | **良好** |

### 3.2 病态矩阵特征

| 特征 | 量级 |
|------|------|
| 最小主元 | 1e-15 - 1e-14 |
| 最大主元 | 500 - 2000 |
| 条件数 κ(A) | 10¹⁶ - 10¹⁷ |
| 数值性态 | **数值奇异**（接近机器精度极限） |

### 3.3 病态性来源推测

三个文件的病态矩阵索引分布完全一致（偶数索引病态），推测：
1. 这些矩阵可能来自同一组"种子矩阵"的扰动生成
2. 偶数索引的矩阵可能对应某种病态物理工况
3. 病态性不是随机产生的，而是数据集的系统性特征

## 4. 对性能测试的影响

### 4.1 之前测试的问题

之前 reported 的性能测试结果（Blockwise 1.37x 快，283/288 获胜）**存在问题**：
- 测试包含了大量病态矩阵（204 个）
- 病态矩阵的求逆结果完全错误（残差 1e+17 到 1e+19）
- 在病态矩阵上比较"速度"没有实际意义

### 4.2 后续测试建议

1. **仅使用 84 个可逆矩阵进行性能对比**
2. **验证残差**：对每个求逆结果计算 ||A·A⁻¹ - I||_F，确保 < 1e-10
3. **分类报告**：分别报告在良态矩阵和病态矩阵上的表现

## 6. 结论

1. **288 个矩阵中仅 84 个（29.2%）数值可逆**，其余 204 个为病态矩阵
2. 病态矩阵条件数达 10¹⁶-10¹⁷，求逆结果无意义
3. 之前的性能测试包含了病态矩阵，结果需要重新验证
