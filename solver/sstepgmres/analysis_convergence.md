# s-step GMRES 收敛性分析：s 参数选择

## 概述

本文档分析 s-step GMRES 中 s 参数（s=2, 3, 4）对收敛性的影响，解释为什么 **s=3 是最佳平衡点**。

---

## 1. Power Basis 向量的"斜度"问题

### 1.1 什么是 Power Basis

s-step GMRES 使用 Power Basis 构建 Krylov 子空间：

```
每个块生成 s 个向量: [v, Av, A²v, ..., A^(s-1)v]

其中:
  v  = 初始向量
  Av = 矩阵作用于 v
  A²v = 矩阵作用于 Av
  ...
```

### 1.2 Power Basis 向量永远不正交

对于任何 s ≥ 2，Power basis 向量之间**永远不正交**：

```
<v, Av> = vᵀAv ≠ 0        (除非 v 是 A 的特征向量)
<Av, A²v> ≠ 0              (几乎总非零)
<A²v, A³v> ≠ 0             (几乎总非零)
...
```

### 1.3 为什么 s 越大向量越"斜"

矩阵 A 有不同大小的特征值 λ₁ < λ₂ < ... < λₙ。将向量 v 分解到特征向量方向：

```
v = c₁u₁ + c₂u₂ + ... + cₙuₙ

Aᵏv = c₁λ₁ᵏu₁ + c₂λ₂ᵏu₂ + ... + cₙλₙᵏuₙ
```

随着 k 增大，**大特征值对应的分量被指数放大**：

```
A⁰v: 各方向分量比例 ≈ c₁ : c₂ : ... : cₙ
A¹v: 比例变成    c₁λ₁ : c₂λ₂ : ... : cₙλₙ
A²v: 比例变成    c₁λ₁² : c₂λ₂² : ... : cₙλₙ²  ← 越来越偏向大特征值
A³v: 比例变成    c₁λ₁³ : c₂λ₂³ : ... : cₙλₙ³  ← 更加偏斜
```

**结果**：k 越大，Aᵏv 越偏向最大特征值方向，与 v 的夹角越大。

## 2. Gram 矩阵 W 与条件数

### 2.1 Gram 矩阵定义

Gram 矩阵 W 描述 Power basis 向量之间的"夹角"：

```
W[i,j] = <Aⁱv, Aʲv>

W 是 s×s 对称正定矩阵
```

### 2.2 条件数的意义

条件数 κ(W) 衡量 W 接近奇异的程度：

```
κ(W) = λ_max / λ_min

κ(W) 越大：
  - W 越接近奇异
  - 求解 W·h = projections 越不稳定
  - 数值误差被放大的程度越高
```

### 2.3 不同 s 值的典型条件数

对于各向异性矩阵 (eps=0.01)：

| s | κ(W) 典型值 | 数值稳定性 |
|---|------------|----------|
| 2 | ~7         | 很稳定    |
| 3 | ~16        | 稳定      |
| 4 | ~40        | 开始危险  |
| 5 | ~100       | 危险      |

## 3. s 参数对收敛的影响

### 3.1 每块覆盖的 Krylov 维度

```
s=2: 每块生成 [v, Av]           → 覆盖 2 维
s=3: 每块生成 [v, Av, A²v]      → 覆盖 3 维
s=4: 每块生成 [v, Av, A²v, A³v] → 覆盖 4 维
```

**直觉**：s 越大，每块覆盖的 Krylov 维度越多，应该收敛越快。

### 3.2 为什么 s=3 比 s=2 好

```
s=2 的探险队：
  每次出发，探索 2 个方向点
  [起点, 走1步]
  
s=3 的探险队：
  每次出发，探索 3 个方向点
  [起点, 走1步, 走2步]
  
结果：
  s=3 的探险队每次收集更多信息，更快找到最优解！
```

**实测数据**（各向异性矩阵 n=10000）：

| s | 收敛块数 | 总 Krylov 维度 | 通信次数 | Restart 次数 |
|---|----------|---------------|----------|-------------|
| 2 | 65       | 130           | 130      | 3           |
| 3 | 38       | 114           | 76       | 2           |

**结论**：
- s=3 用更少的总向量数（114 vs 130）收敛
- s=3 通信减少 42%（76 vs 130）

### 3.3 为什么 s=4 效果变差

当 s=4 时：

```
问题 1: κ(W) ≈ 40，W 接近奇异
  → 求解 W·h = projections 不准确
  → 正交化误差大

问题 2: A³v 几乎平行于最大特征向量
  → 与 v 夹角很大
  → 正交化困难

问题 3: 误差累积
  → 残差估计偏离真实值
  → 可能不收敛或收敛慢
```

## 4. 图示对比

### 4.1 向量"斜度"示意图

```
s=2: [v, Av]
     方向差异小，还比较"正"
     
         v
         │
         │
         └──── Av
               (夹角较小)

s=3: [v, Av, A²v]
     A²v 明显偏向一个方向
     
         v
         │
         │  Av
         │  ╱
         │ ╱
         └────── A²v
                  (夹角较大)

s=4: [v, Av, A²v, A³v]
     A³v 几乎平行于最大特征向量
     
         v
         │
         │  Av    A²v
         │  ╱    ╱
         │ ╱    ╱
         └────────── A³v
                      (几乎水平)
```

### 4.2 收敛过程对比

```
s=2:
  Block → [v, Av] → Allreduce → 正交化 → Block → ...
  每块贡献 2 个向量，需要更多块才能覆盖足够空间

s=3:
  Block → [v, Av, A²v] → Allreduce → 正交化 → Block → ...
  每块贡献 3 个向量，更快覆盖目标空间
  
s=4:
  Block → [v, Av, A²v, A³v] → Allreduce → 正交化(不稳定!) → ...
  虽然每块 4 个向量，但正交化误差大，抵消了优势
```

## 5. 数学分析

### 5.1 Krylov 子空间等价性

理论上，相同总维度的 Krylov 子空间是等价的：

```
K_{60} = span{r, Ar, A²r, ..., A⁵⁹r}

s=2 需要 30 个块：每块 [A²ᵏr, A²ᵏ⁺¹r]
s=3 需要 20 个块：每块 [A³ᵏr, A³ᵏ⁺¹r, A³ᵏ⁺²r]
s=4 需要 15 个块：每块 [A⁴ᵏr, A⁴ᵏ⁺¹r, A⁴ᵏ⁺²r, A⁴ᵏ⁺³r]
```

### 5.2 正交化代价

由于 Power basis 不正交，需要通过求解线性系统来正交化：

```
Scalar1 正交化：求解 W·h = projections

误差放大因子 ≈ κ(W)
```

| s | κ(W) | 误差放大 |
|---|------|---------|
| 2 | ~7   | 7 倍    |
| 3 | ~16  | 16 倍   |
| 4 | ~40  | 40 倍   |

**结论**：s=4 时误差放大 40 倍，可能抵消多覆盖向量带来的收益。

## 6. 实测结果汇总

### 6.1 五对角矩阵 (type=0)

| 维度 n | s | 收敛块数 | 通信次数 | 最终残差 |
|--------|---|----------|----------|----------|
| 10000  | 2 | 2        | 4        | ~1e-8    |
| 10000  | 3 | 2        | 4        | ~1e-8    |

**说明**：五对角矩阵条件数好，s=2 和 s=3 都能快速收敛。

### 6.2 各向异性矩阵 (type=1, eps=0.01)

| 维度 n | s | 收敛块数 | 通信次数 | Restart | 最终残差 |
|--------|---|----------|----------|---------|----------|
| 10000  | 2 | 65       | 130      | 3       | ~1e-8    |
| 10000  | 3 | 38       | 76       | 2       | ~1e-8    |
| 10000  | 4 | 不稳定   | -        | -       | -        |

**说明**：各向异性矩阵条件数差，s=3 效果最好。

## 7. 结论与建议

### 7.1 s 参数选择指南

| s | 适用场景 | 优点 | 缺点 |
|---|---------|------|------|
| 2 | 极端困难问题 | 最稳定 | 收敛较慢 |
| 3 | **推荐（默认）** | 平衡稳定性和效率 | - |
| 4+ | 不推荐 | - | 数值不稳定 |

### 7.2 为什么 s=3 是黄金平衡点

```
1. 效率方面：
   - 每块覆盖 3 维 Krylov 空间
   - 通信次数是传统 GMRES 的 1/3

2. 稳定性方面：
   - κ(W) ≈ 16，误差放大可接受
   - 正交化仍然准确

3. 综合效果：
   - 比s=2收敛更快（更少通信）
   - 比s=4更稳定（不会崩溃）
```

### 7.3 论文推荐

多篇 s-step GMRES 论文（如 Demmel 等人的工作）推荐 **s=2 或 s=3**，这符合我们的实测结论。
