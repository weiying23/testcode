# 大规模问题残余停滞分析

## 测试数据汇总

| 问题规模 | Krylov向量数 | Givens估计残余 | 真实残余 | 比值 |
|---------|-------------|---------------|---------|------|
| n=100 | 6 | 1.4e-12 | 7.3e-12 | ~5x |
| n=1000 | 6 | 1.5e-12 | 7.9e-12 | ~5x |
| n=100000 | 90 | 3.7e-10 | 1.6e-9 | ~4x |

## 核心问题

**不是正交性损失，而是Krylov子空间饱和**

### 现象

1. 小规模问题(n≤1000): 6个Krylov向量即可收敛到1e-12
2. 大规模问题(n=100000): 
   - Block 1-2 (6 Krylov向量): 残余从1.6e-5降到4.2e-9
   - Block 3+: 残余几乎停滞，每块只降约1e-11

### 分析

```
残余变化曲线 (n=100000):

Block 1: 1.6e-5 → (下降5000倍)
Block 2: 4.2e-9 → (下降约10倍)
Block 3: 4.0e-10 → (几乎停滞)
Block 4-30: 每块下降约1e-11
```

这表明:
- 前6个Krylov向量捕获了主要误差成分
- 后续Krylov向量对残余减少贡献极小

## 数学解释

### ILU0预处理器的局限性

对于2D Poisson型矩阵:
- 条件数 κ(M⁻¹A) ≈ O(h⁻¹) = O(√n)
- n=100000 → κ ≈ 316

ILU0预处理:
- 有效消除最坏条件数成分
- 但残余的"硬化"成分仍需要大量Krylov向量

### GMRES收敛理论

```
残余界: ||r_m|| ≤ C·min|p(λ)|·||r_0||
```

对于预处理后的矩阵:
- 主要特征值(≈1附近): 快速收敛
- 边缘特征值(远离1): 需要多项式p覆盖

当边缘特征值分布分散时:
- 需要高阶多项式(m大)
- 但功率基在高阶时数值不稳定

## 改进方案

### 方案1: 更好的预处理

| 预处理器 | 条件数改善 | 特点 |
|---------|-----------|------|
| ILU(k) | k越大越好 | 内存增加 |
| AMG | O(1)条件数 | 最优选择 |
| SSOR | 中等 | 简单实现 |

**推荐: AMG (代数多重网格)**
- 对Poisson型问题条件数O(1)
- 与问题规模无关的收敛速度

### 方案2: 重启GMRES

```
GMRES(m) 重启策略:
1. 构建Krylov子空间 K_m
2. 计算最优解 x_m
3. 重启: r = b - Ax_m, 新子空间从r开始
```

优点:
- 重置正交性
- 内存可控

缺点:
- 每次重启丢失信息
- 可能停滞(如果残余方向固定)

### 方案3: 增强正交化

当前使用CGS (Classical Gram-Schmidt):
- 快速但易累积误差

改进选项:
1. **MGS**: Modified Gram-Schmidt, 更稳定
2. **Reorth**: 重复正交化 (twice CGS)
3. **Hybrid**: 对W矩阵使用Cholesky分解

### 方案4: 多项式基改进

功率基问题:
```
W矩阵条件数随s增长:
s=2: cond(W)≈7
s=3: cond(W)≈16
s=5: cond(W)≈128
```

改进基:
- **Chebyshev基**: 更稳定的数值性质
- **Newton基**: 需要特征值估计

## 实用建议

### 针对当前问题 (n=100000)

**短期改进**:
1. 使用重启 (m=30, 每30块重启)
2. 放宽收敛容忍度 (1e-8 实用精度)

**长期改进**:
1. 实现AMG预处理器
2. 实现Chebyshev多项式基
3. 添加MGS或Reorth正交化

### 效果预估

| 改进 | 预期效果 |
|------|---------|
| AMG预处理器 | 收敛到1e-10只需O(log n)迭代 |
| 重启 | 避免停滞但收敛变慢 |
| Chebyshev基 | 允许更大s值 (s=5稳定) |
| MGS | 减小正交性误差 |

## 结论

当前残余停滞的根本原因是:
1. **ILU0预处理不够强**: 对于大规模Poisson问题,条件数仍有O(√n)
2. **Krylov子空间饱和**: 前几个向量捕获主要成分,后续贡献小

最佳解决方案是实现**AMG预处理器**,可将收敛速度变为与问题规模无关。

次优方案是**重启+放宽容忍度**,对于实用精度(1e-6~1e-8)足够。
