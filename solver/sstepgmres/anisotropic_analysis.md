# 各向异性矩阵收敛性与通信分析

## 问题1：为什么各向异性矩阵收敛性差？

### 数学原因

各向异性扩散方程:
```
-ε·∂²u/∂x² - ∂²u/∂y² = f
```

当 **ε << 1** 时:
- x方向扩散极慢 (系数 ε)
- y方向扩散正常 (系数 1)

### 对迭代求解器的影响

| 因素 | 五对角矩阵 | 各向异性矩阵 |
|------|-----------|-------------|
| 条件数 | O(h⁻²) | O(ε⁻¹) |
| ε=0.01时 | ~400 | ~100 |
| 特征值分布 | 相对集中 | 分散 (x,y方向差异大) |
| Krylov效率 | 高 | 低 |

### 收敛理论

GMRES 收敛界:
```
||r_k|| / ||r_0|| ≤ C · (κ-1)/(κ+1)^k
```

- 条件数 κ 越大，收敛越慢
- ε=0.01 → κ≈100 → 需要 O(100) 次 Krylov 迭代

## 问题2：为什么通信次数高这么多？

### 通信模式

s-step GMRES: **每个块迭代 1 次 Allreduce**

| 矩阵类型 | 收敛Krylov维度 | 块数(s=3) | 通信次数 |
|---------|--------------|----------|---------|
| 五对角 | 6 | 2 | 3 |
| 各向异性 | >90 | 30+ | 31+ |

### 关键点

1. **收敛需要更多块**: 各向异性问题的条件数大，需要更多Krylov向量才能捕捉解的所有特征方向

2. **每块一次通信**: 无法避免，这是算法的固有特性

3. **但仍有加速**: 
   - 标准GMRES: 90个向量 → 180次通信
   - s-step GMRES: 30个块 → 31次通信
   - **加速比: 5.8x**

---

## 改进建议

对于各向异性问题:

1. **更好的预处理**: 
   - 块ILU (保留更多填充)
   - 代数多重网格 (AMG)
   - 不完全Cholesky (IC)

2. **增大m**: 增加重启前的Krylov维度

3. **使用多项式基**: Chebyshev多项式替代幂基 {r, Ar, A²r, ...}

4. **减小s**: s=2 更稳定 (但通信效率略降)
