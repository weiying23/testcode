# GMRES 迭代求解器

一个用于求解大型稀疏线性方程组 Ax = b 的 GMRES (Generalized Minimal Residual) 迭代求解器。

## 功能概述

本程序实现了 GMRES 算法，并对比了三种不同预条件策略的求解性能：

- **无预条件** - 原始 GMRES 算法
- **ILU0 预条件** - 不完全 LU 分解（零填充）
- **ILUT 预条件** - 阈值不完全 LU 分解

## 主要数据结构

| 结构体 | 用途 |
|--------|------|
| `TridiagMatrix` | 三对角矩阵（主对角线、上对角线、下对角线） |
| `CSRMatrix` | 稀疏矩阵的压缩行存储格式 (Compressed Sparse Row) |
| `ILUFactors` | ILU 分解的 L 和 U 因子 |

## 核心算法

### 1. 测试矩阵生成
生成一个 1000×1000 的高条件数三对角矩阵（条件数约 1e6），用于模拟病态线性系统。主对角线从大值逐渐减小，使条件数变大。

### 2. ILU 预条件器
- **ILU0**: 零填充的不完全 LU 分解，保持原始稀疏模式
- **ILUT**: 基于阈值的不完全 LU 分解，可控制填充元数量

### 3. GMRES 求解器
- 使用 Arnoldi 迭代构建 Krylov 子空间
- 使用 Gram-Schmidt 正交化
- 使用 Givens 旋转求解最小二乘问题

### 4. 条件数估计
- 使用幂迭代估计最大特征值
- 使用反幂迭代估计最小特征值

## 编译与运行

```bash
./run.sh
```

`run.sh` 使用 `mpicc` 编译，针对 Apple M4 优化，启用 OpenMP 并行：

```bash
mpicc -O3 -mcpu=apple-m4 -fopenmp gmres_ilu.c -o test
mpirun -np 1 ./test
```

## 输出示例

程序输出三种方法的收敛对比：

```
===== 算法性能对比 =====
条件数: 1.00e+06

方法            迭代次数   相对速度   时间 (秒)
------------------------------------------------
无预条件        120        1.00       0.0523
ILU0            45         2.67       0.0234
ILUT            38         3.16       0.0198

分析:
- ILU0 比无预条件快 2.67 倍
- ILUT 比无预条件快 3.16 倍
- ILUT 比 ILU0 额外提高了 18.35% 的收敛速度
```

## 参数配置

在 `main()` 函数中可调整以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `n` | 1000 | 矩阵大小 |
| `tol` | 1e-8 | 收敛容差 |
| `tau` | 0.01 | ILUT 阈值 |
| `lfil` | 5 | ILUT 每行最大非零元数 |
