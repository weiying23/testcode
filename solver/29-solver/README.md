# Hotspot 求解器

本代码实现了稀疏线性方程组的**前向/后向替换求解**算法。

## 算法说明

### `forward_compute` (前向替换)
用于求解**下三角线性系统**（包含对角线）：

1. 对每个点 `iPoint`，等待所有前置依赖节点（`col_ind` 中的列索引）计算完成
2. 计算低阶项：`low_prod = sum(A_ij * x_j)` （j < i）
3. 提取对角块矩阵
4. 使用**高斯消元法**将系统转换为上三角形式
5. 通过**反向代入**（Backward substitution）求解当前点的值
6. 标记当前点为"就绪"状态

### `backward_compute` (后向替换)
用于求解**上三角线性系统**：

- 从后往前遍历（`end-1` 到 `0`）
- 计算对角项和上三角部分的贡献
- 同样采用高斯消元 + 反向代入的模式

## 应用场景

这是一个典型的**迭代求解器内核**，常用于：
- 计算流体力学（CFD）仿真
- 有限元/有限体积法求解偏微分方程（PDE）
- 直接数值模拟（DNS）中的压力泊松方程求解

## 实现特点

- **OpenMP 并行**：使用 `#pragma omp parallel for` 实现多线程并行
- **依赖控制**：通过 `isReady` 数组和 `#pragma omp flush` 处理数据依赖
- **块结构**：支持多变量（`nvar`），每个点有多个未知数
- **稀疏存储**：采用压缩行格式（CSR）存储矩阵（`row_ptr`, `col_ind`, `dia_ptr`）
